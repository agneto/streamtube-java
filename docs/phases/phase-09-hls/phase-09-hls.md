# Phase 09 — HLS Adaptive Streaming (plan)

## Objective

Every newly processed video gets an HLS ladder (multi-quality, TS segments) generated by the
worker; the API serves the playlists (applying the visibility matrix and counting views) with
segment lines rewritten to presigned URLs — bytes keep flowing straight from storage.

---

## Technical Specifications

### Data Model — migration V11

**`videos` — one nullable column:**

| Column | Type | Notes |
|--------|------|-------|
| hls_master_key | varchar(500) | e.g. `hls/{slug}/master.m3u8`; null = no HLS (pre-phase catalog) |

### Worker — transcoding

New worker-only port (wired in `WorkerBeans`, like `VideoAnalyzer`):

```java
public interface VideoTranscoder {
  /** Renders the HLS ladder into workDir; returns the rendition names actually produced. */
  List<String> transcodeToHls(String inputUrl, Path workDir, int sourceHeight);
}
```

`FfmpegVideoTranscoder`: one ffmpeg invocation per rendition
(`-vf scale=-2:{h} -c:v libx264 -c:a aac -hls_time 6 -hls_list_size 0 -hls_segment_filename ...`),
then a hand-written `master.m3u8` (`#EXT-X-STREAM-INF` with BANDWIDTH/RESOLUTION per rendition).
Ladder: source ≥720 → [720, 480, 360]; ≥480 → [480, 360]; else [sourceHeight]. Never upscale.

`ProcessVideoUseCase` extension (still non-transactional around external work): probe → thumbnail
→ **transcode to temp dir → upload every file under `hls/{slug}/`** → `markReady(..., hlsMasterKey)`.
Temp dir deleted in `finally`. `ProbeResult` gains the source `height` (from the video stream).

### API — playlist serving

`StoragePort` gains `String getObjectText(String key)` (playlists are small UTF-8 text).

- `GetHlsMasterUseCase(slug, viewerUserId)`: read rule via `VideoViewAccess` (draft → 404
  non-owner); 404 when `hls_master_key` is null; **counts the view when published** (same
  `incrementViews`); rewrites each rendition line (`{rendition}/playlist.m3u8`) to the API path
  `/api/v1/videos/{slug}/hls/{rendition}/playlist.m3u8`.
- `GetHlsPlaylistUseCase(slug, rendition, viewerUserId)`: same read rule; rendition validated
  (`[0-9]{3,4}p`); every segment line (`seg-NNN.ts`) rewritten to
  `presignStream`-style URLs with the **segment TTL** (`hls.segment-url-ttl-seconds`, default
  6 h); non-URI lines (`#EXT-X-*`) pass through untouched.
- Responses served `application/vnd.apple.mpegurl`, no caching (`Cache-Control: no-store` — each
  fetch mints fresh signatures).

### Config

| Property | Env | Default |
|----------|-----|---------|
| `hls.segment-url-ttl-seconds` | `HLS_SEGMENT_URL_TTL_SECONDS` | 21600 (6 h) |

### Contracts

- `GET /videos/{slug}/hls/master.m3u8` → 200 playlist / 404 (unknown, draft for non-owner, or no
  HLS) — public route (covered by `GET /api/v1/videos/**`).
- `GET /videos/{slug}/hls/{rendition}/playlist.m3u8` → 200 playlist / 404.
- `VideoInfoResponse.hlsUrl`: `/api/v1/videos/{slug}/hls/master.m3u8` or null.
